# 漫画進捗管理

漫画制作のページごとの作業時間を記録して、締切までの残り時間とこれからの作業量をひと目で確認するための Web アプリ（PWA）です。

**▶ アプリを開く: https://nicolai4875-rgb.github.io/manga-progress/**

- iPad の Safari で開いて、共有ボタン →「ホーム画面に追加」で使えます（Mac / Windows のブラウザでも動きます）
- 記録はすべて使う人の端末の中だけに保存され、外部には送信されません。アカウント登録も不要です
- 一度開けばオフラインでも使えます

## 主な機能

- 原稿 PDF を取り込んでページのサムネイルを一覧表示
- ページごとの目標時間と作業時間の計測（作業開始・停止）
- 目標時間の消化率をサムネイルに「容器」として表示、超過中ページの判別
- 締切まで・今日残り・概算残り時間の表示
- 作業中画面（Slide Over で CLIP STUDIO PAINT の横に出して使えます）
- 話別・日別の履歴、作業ログの修正・取消
- CSV 出力、バックアップの書き出し・復元

使い方はアプリ内の「？」、または [help.html](./help.html) を見てください。

## 更新するとき

ファイルを変更したら、`sw.js` の `VERSION` を必ず上げてください（上げないと、使っている人の端末に古いファイルが残ります）。

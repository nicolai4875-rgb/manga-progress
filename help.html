漫画進捗管理 の使い方

ページごとの作業時間を記録して、締切までの残り時間とこれからの作業量をひと目で確認するためのツールです。

データについて
記録はすべてこの端末の中だけに保存され、インターネット上には送信されません。アカウント登録も不要です。その代わり、アプリを削除するとデータも消えるので、ときどきバックアップを書き出してください。

1. はじめに（ホーム画面に追加）

  1. iPad の Safari でこのページを開きます。
  2. 共有ボタン（□に↑のアイコン）→ 「ホーム画面に追加」。
  3. ホーム画面にできた 「漫画進捗」 のアイコンから起動します。
  • 必ずホーム画面のアイコンから使ってください。 Safari のタブとホーム画面のアプリでは、データが別々に保存されます。
  • Safari のタブのままだと、しばらく使わないとデータが消されることがあります。ホーム画面のアプリなら自動では消えません。
  • 一度開けば、インターネットに繋がっていなくても使えます。

2. 基本の使い方

  1. 「＋ 新しい話」で作品名・話数・総ページ数・締切を入力。
  2. 「PDF取込」で原稿PDFを選ぶ → 全ページのサムネイルが並びます。
  3. 各ページの「目標」欄に時間を入力（例 6 や 6:30）。
  4. 作業するページの 「▶ 作業開始」 → 画面が「作業中」表示に切り替わります。
  5. 作業が終わったら 「■ 停止」。作業時間が記録され、一覧に戻ります。
  6. そのページが仕上がったら 「完成」。
  7. 作業の区切りに最新の原稿をPDFで書き出し、もう一度「PDF取込」 → サムネイルだけ最新になります（記録はそのまま）。

3. CLIP STUDIO PAINT と一緒に使う

作業開始すると、アプリ全体が大きな「作業中」表示に切り替わります。

このページ   4:18 / 6:00
締切まで   2日 05:31
今日残り      4:24   ← 今日の24:00まで
概算残り     18:40   ← この話の残り作業量（目安）
超過中         1P

[ ■ 停止 ]  [ 一覧 ]
  • CLIP STUDIO に切り替えても計測は続きます。 時間は「開始時刻から今まで」で計算するので、このアプリを閉じていても正確です。
  • 残り時間を見ながら描きたいときは、iPad の Slide Over や Split View でこのアプリを CLIP STUDIO の横に細く出しておくのがおすすめです（ステージマネージャ対応の iPad なら小さなウィンドウにもできます）。
  • 一覧：計測を続けたまま一覧に戻ります。上部の青いバーの「ミニ表示」で作業中表示に戻れます。
  • iPad では、他のアプリの上にこのアプリを重ねて表示することはできません。
CLIP STUDIO の複数ページ書き出しで原稿を PDF にして「ファイル」アプリに保存してから、このアプリの「PDF取込」で選んでください。Split View 中なら「ファイル」アプリから PDF をドラッグ＆ドロップすることもできます。

  • 入力したら改行（return）で確定し、次のページの欄に移ります。
  • 目標時間を入れていないページは作業開始できません（未入力の欄は黄色）。
  • そのページで最初に作業開始した時点の目標が固定されます（🔒）。入力ミスはカードの ≡（作業ログ）画面から直せます。

5. ページカードと集計の見かた

サムネイルは「容器」になっていて、目標時間をどれだけ使ったか（実績 ÷ 目標）に合わせて下から色が満ちていきます。完成度ではありません。100%になっても自動で完成にはなりません。

6. 記録の修正・取消

  • カードの ≡ で、そのページの作業ログを開き、開始・終了時刻の修正や削除ができます。
  • 右上の 「↶ 取消」で直前の操作を取り消せます（キーボード接続時は ⌘+Z）。アプリを閉じると取消の履歴は消えます。
  • 完成を間違えたときは「完成済」をもう一度押すと解除できます。

7. アプリが閉じられていたとき

他のアプリを使っている間に、iPad がこのアプリを自動で終了させることがあります。計測の記録は消えません。次に開いたときに「計測中の作業があります」と表示されるので、選んでください。

今の時刻で終了して記録今まで作業していたものとして記録
最後に見ていた時刻で記録その時点で作業もやめていた場合
指定した時刻で記録終了時刻を自分で指定

8. 履歴

上部の「履歴」で、話別（ページごとの目標・実績・差分）と日別（その日の総作業時間とログ）を確認できます。0時をまたいだ作業は日付ごとに分けて集計されます。

9. バックアップ・CSV

右上の 「データ」 から操作します。

  • バックアップを書き出す：全データ（サムネイル込み）を1つのファイルにします。「保存する」→ 「"ファイル"に保存」で iCloud Drive などに保存してください。
  • バックアップから復元：書き出したファイルを選ぶと、その内容に置き換わります（今のデータは消えます）。機種変更や、別の端末に移すときにも使えます。PC版（Windows）の data.json も読み込めます（サムネイルは PDF を取り込み直してください）。
  • CSV出力：Excel・Numbers で開ける形式。作業ログが1行ずつ入ります。
  • 最後のバックアップから7日以上経つと、画面上部でお知らせします。

10. 困ったとき

データが消えた・空になった

Safari のタブで開いていませんか？ ホーム画面のアイコンから開いてください（データが別になっています）。消えてしまった場合は、バックアップから復元してください。

PDFが読み込めない

パスワード付きのPDFは読み込めません。ページ数がとても多い・解像度がとても高いPDFは時間がかかります。

新しいバージョンにしたい

アプリを一度完全に閉じて（アプリスイッチャーで上にスワイプ）開き直すと、更新されます。

対応環境

iPadOS 16 以降の Safari を推奨します。Mac・Windows の Chrome / Edge / Safari でも使えます（データは端末ごとに別々です）。
